# Contributing

Thank you for your interest in **rquasar**.

## This project does not accept unsolicited pull requests

Pull requests opened against this repository are **closed automatically**. This
is deliberate, and in line with a growing number of major open-source projects
that have tightened how they handle unsolicited and machine-generated
contributions.

We evaluate **proposals, not patches**. A good proposal explains the problem,
the purpose, and the reasoning — the *why* before the *how*. The maintainer then
does the analysis and the implementation. This keeps the codebase coherent,
auditable, and small, and puts the emphasis on the intent of a change rather
than the volume of code.

## How to contribute

1. **Open an issue** describing the problem or idea: what, why, and the context.
2. Discuss it there. If it is a good fit, the maintainer implements it.
3. Bug reports with a minimal reproducible example are especially welcome.

## What is not accepted

- **Unsolicited pull requests** — closed automatically.
- **AI-generated content** — code, documentation, or images produced by
  generative models. Provenance, licensing, and correctness cannot be reliably
  verified, so such contributions are not merged.
- **Duplicated or derivative content**, and large mechanical diffs.

## Security

Please report security issues privately to the maintainer, not in a public
issue.
